# Description

The objective of this module is to manage the login for the user and the restaurant. Here the users
should be able to:

* Login with their email.
* Register with their email.
* Register a restaurant with its email.
* Login with the provider of the phone
    * Apple on iOS
    * Google on Android
    * Both in Web
* The module should redirect the user to the HomeScreen is success login or the screen the user was
  trying to navigate before login appear.
